## Question

知识图谱 schema 定稿：节点候选（方案 / 药物 / 分层 / 推荐等级 / 证据类别）里哪些是 node、哪些降为属性；边语义（推荐于(等级) / 适用(分层) / 证据 / 组成于(药物)）精确化。

输入：03 的 7 字段记录（只含方案名，不含药物）＋「常用方案」给药表（方案 → 药物/剂量，是 `组成于` 边的原料）。基于 [03 结构化决策记录 schema 定稿]。

## Answer

**模型：reify（决策记录作 hub 节点）**。6 节点 5 边：

| 节点 | 说明 |
|---|---|
| 推荐决策 | 03 的一条记录；属性 = 来源页码 |
| 方案 | 方案名（TCbHP、T-DM1…） |
| 药物 | 组成成分（卡铂、曲妥珠单抗…） |
| 分层 | 单节点；属性 = 治疗阶段 / 人群 / 分层条件 |
| 推荐等级 | Ⅰ / Ⅱ / Ⅲ（3 实例） |
| 证据类别 | 1A / 1B / 2A / 2B / 3（5 实例） |

| 边 | 三元组 |
|---|---|
| 方案 | 推荐决策 -[:方案]→ 方案 |
| 适用于 | 推荐决策 -[:适用于]→ 分层 |
| 等级 | 推荐决策 -[:等级]→ 推荐等级 |
| 证据 | 推荐决策 -[:证据]→ 证据类别 |
| 组成于 | 方案 -[:组成于]→ 药物（多对多；剂量/周期不进图） |

**关键裁定**：等级/证据要成节点，就必须 reify（否则等级无法绑定「哪一分层下的哪一方案」）；分层不做拆分（阶段/人群是枚举值，拆开徒增节点数）；剂量/周期只属于给药表，不进图。
