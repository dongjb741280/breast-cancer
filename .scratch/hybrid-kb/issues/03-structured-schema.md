## Question

结构化决策记录 schema 定稿：一条「推荐决策」的规范字段（分层/适应症、方案、推荐等级、证据类别、来源页码、注释？）与规范术语（术语落到 `CONTEXT.md`）。

对齐 [01 系统输入 schema 与金标准结构摸底] 的金标准形态 + [02 guide.md 推荐等级与证据类别噪声清单及归一化规则] 的归一化输出。

## Answer

**记录粒度**：一条推荐决策 = 一个 (分层, 方案) 二元组。表格单元格里多个方案拆成多条记录。

**最终 7 字段**：

| 字段 | 类型 | 说明 |
|---|---|---|
| 治疗阶段 | enum: 新辅助 / 辅助 / 晚期解救 | 决策所属诊疗时点 |
| 人群 | label: HER2+ / HR+ / HR− / HER2 低表达 | 患者亚型标签 |
| 分层条件 | 自由文本 | pCR / non-pCR / 曲妥珠单抗敏感… |
| 方案 | string | 方案名，如 TCbHP、T-DM1 |
| 推荐等级 | enum: Ⅰ / Ⅱ / Ⅲ | 经 02 归一化 |
| 证据类别 | enum: 1A / 1B / 2A / 2B / 3 | 经 02 归一化 |
| 来源页码 | int | 指南页码，供「证据依据」溯源 |

**术语**：已落 `CONTEXT.md`（推荐决策 / 方案 / 推荐等级 / 证据类别 / 治疗阶段 / 人群 / 分层条件 / 金标准）。

**范围裁定**：
- `更新要点`（增量改动叙事）不进结构化层——只以决策表为准。
- `常用方案`给药表（方案 → 药物/剂量）归 [04 知识图谱节点/边 schema 定稿] 抽 `组成于` 边，决策层只存方案名。
