## Question

检索分路合并算法定稿：结构化层精确/图查询 + 正文 BM25 + 向量，三路结果如何统一排序（分路合并 vs RRF vs 加权）。

基于 [03 结构化决策记录 schema 定稿] / [04 知识图谱节点边 schema 定稿] / [05 embedding 与向量库选型] 的产物形态。

## Answer

**融合算法定稿 = 分层融合（非扁平 RRF）**

- **架构 = 分层**：结构化决策记录（方案+等级+证据）是「答案层」排顶层，按 推荐等级 Ⅰ>Ⅱ>Ⅲ 排序；正文 chunk 是「证据层」次层。两者不同类，不混排。
- **结构化/图匹配 = 精确优先**：治疗阶段 + 人群 + 分层条件 精确命中 → 取该分层全部推荐决策，按等级排序；无精确才降级到语义匹配。
- **正文 BM25 + 向量 = RRF**：BM25 top-k 与 向量 top-k 各自排序，reciprocal rank 合并。
- **空结果降级**：结构化层无命中 → 正文层兜底 + 显式标记「未命中结构化决策」。
