三个容易混淆的点

  1. 检索不判断，判断才检索。③ 的知识检索永远返回方案，不判断「该不该给」。② 的 LLM 先决定进不进决策树、资料够不够，够才调 ③。光有检索 ≠ 能回答临床问题。
  2. 「资料不足」是正确答案。② 里 资料充足=false 时走「否」分支停手，输出「需补充 XX」——评测按满分算，不是 0 分。
  3. 两条链路分开。「离线构建」（guide.md → 索引）只跑一次、是确定性代码；「在线推理」五步每次病例跑一遍，其中 ②⑤ 调 LLM。
