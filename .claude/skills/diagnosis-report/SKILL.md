# 乳腺癌诊疗：综合诊断报告 + 决策链追踪

一份病历 + CSCO 指南，产出两样互补产物：

1. **综合诊断报告**（面向临床：诊断、分型、分期、治疗评价、后续建议）
2. **决策链追踪 A→U**（回溯该病例走到了哪个节点、凭什么）+ 高亮 mermaid 图

两者共享同一份特征抽取：一次读取、一次抽取、两个输出。全程由 Claude 直接读病历与指南、自行判断，**不依赖任何外部脚本**（生成图用 `mmdc` 渲染，见「第六步」）。

   | REAL-003 | `Data_Cleaning/doc/系统输入/REAL-003-大悟县首程-脱敏映射.json` |
   | REAL-004 | `Data_Cleaning/doc/系统输入/REAL-004-首程2-脱敏映射.json` |
   | REAL-005 | `Data_Cleaning/doc/系统输入/REAL-005-首程3-脱敏映射.json` |
   | REAL-006 | `Data_Cleaning/doc/系统输入/REAL-006-深圳南山入院-严格标准版.json` |
   | REAL-007 | `Data_Cleaning/doc/系统输入/REAL-007-深圳南山入院-严格标准版.json` |

2. **JSON 文件路径** → 直接读，取 `data["patient_data"]`。
3. **粘贴的自由文本**（住院志/病程/出院记录等）→ 直接当作病历摘要。

- 指南固定路径：`Data_Cleaning/process_ocr/output/guide.md`（CSCO 乳腺癌诊疗指南）。

- 评测参照（可选）：`Data_Cleaning/doc/系统输入/7例真实病例-患者基本情况与诊疗金标准.md`。

读 JSON 时，`patient_data` 里**所有带临床信号的字段都读一遍，不要只读叙事文书**。字段→特征映射见「第三步」。

## 第二步：读指南相关章节

guide.md 按章节号组织，按病例所处阶段选读对应章节（用 grep 定位章节标题，不要硬背行号）：

| 章节 | 内容 | 何时读 |
|---|---|---|
| 一、乳腺癌的诊断及检查 | 确诊 / 分子分型 / HER2 判读 | **所有病例**（分子分型与 HER2 判读表必读） |
| 二、乳腺癌的术前新辅助治疗 | 新辅助适应证与方案 | 做过新辅助 / 需判断是否新辅助 |
| 三、乳腺癌的术后辅助治疗 | 辅助化疗 / 内分泌 / 放疗 | 早期术后 / 需判断辅助方案 |
| 四、晚期乳腺癌的解救治疗 | 晚期分型序贯（HER2+/三阴/HR+/HER2低表达） | 复发转移 M1 |
| 五、乳腺癌骨转移 | 骨改良药 / 放疗 / 手术 | 骨转移 |
| 六、乳腺癌脑转移 | 脑实质 vs 脑膜 / 局部治疗 / 中枢活性药 | 脑转移 |
| 七、乳腺癌的治疗管理 | 毒性 / 心脏监测 / 骨髓抑制等 | 有合并症或需管理毒性 |
| 八、年轻乳腺癌 | BRCA / 生育 / 卵巢保护 | <40 岁（尤 <35 岁） |
| 九～十六 | 男性 / 叶状肿瘤 / 生物类似药等 | 按需 |

优先读与「分子分型判读」和「该病例所处治疗阶段」直接相关的段落。HER2 判读表（IHC 0/1+/2+/3+、ISH 判读）是判断 HER2 阳性/低表达/超低表达的依据，**所有病例都要读**。

## 第三步：抽取结构化临床特征

逐条从病历提取，**优先用权威字段，叙事文本兜底；每条都要能指回原文，抽不到就写「未记录」，绝不编造**。

字段→特征映射（结构化为权威、叙事兜底）：

| 字段 | 装的是什么 | 喂给哪些特征 |
|---|---|---|
| `standard_patient` | 性别；其余多为脱敏 PII | 性别 |
| `diagnosis[]` | 诊断名 + 年龄 | 诊断列表、年龄、TNM/分期 |
| `standard_pathology_reports[]` | 病理诊断 + IHC/分子 | **分子分型、ER/PR/HER2/Ki67/FISH、TNM、pCR/RCB（最权威）** |
| `standard_final_operation_records[]` | 术式、术后病理 ypTNM、RCB | 手术、pCR/non-pCR |
| `examine_items[]` | 影像（CT/MR/ECT/超声） | 转移部位、分期 |
| `laboratories[]` | 检验（血常规/生化等） | 骨髓抑制、脏器毒性、肿瘤标志物 |
| `recipe_medicines[]` | 医嘱用药 | 治疗（当前/既往）的结构化来源 |
| `standard_inpatient_documentations[]` | 叙事文书（入院/首次病程/病程摘要/出院） | 兜底：分期、治疗时间轴、手术、pCR |
| `standard_outpatient_medical_records[]` / `standard_out_patient_visits[]` / `standard_in_patient_records[]` | 门诊/住院就诊记录 | 就诊时间轴、补充治疗 |

注意：各字段正文字段名不统一，先扫一眼该字段第一个元素的 key，找到承载文本/诊断/结论的字段再读（病理 `pathology_diagnosis`+`pathology_description`，文书 `record_text`，检验/影像找 `report_name`+所见文本）。叙事文书里跳过知情同意/授权委托/信息确认等模板；`standard_patient` 里的 PII（身份证/手机号等）不读不输出。

### 必抽特征

- **性别 / 年龄**：`standard_patient` 与 `diagnosis[]`（年龄以 `diagnosis[]` 的 `standard_age` 为准，`standard_patient` 常无年龄）。
- **诊断列表**：`diagnosis[]` 所有诊断名去重，标注诊断类型（门诊/入院/出院）。
- **TNM / 分期（区分初始 vs 当前）**：初始 = 最早一次记录；当前 = 最近一次（复发/转移后常 M1 / Ⅳ期）。注意 `MO`→`M0` 的 OCR 误写；术后病理用 `ypT/N`（如 ypT2N1a）。无 TNM 就写「临床/病理分期未记录」。
- **分子分型**（按指南判读）：
  - HER2 **IHC 3+** 或 **FISH/ISH 扩增** → HER2 阳性型（**IHC 3+ 优先于 FISH 结果**：FISH 扩增阴性但 IHC 3+ 仍判阳性）
  - HER2 IHC 1+，或 IHC 2+ 且 FISH 阴性 → HER2 低表达型
  - HER2 **IHC 0 但 ≤10% 浸润癌细胞呈不完整、微弱膜染色** → HER2 超低表达（不能简单归为 HER2 阴性，关系到 T-DXd 适用）
  - ER/PR ≥1% → HR 阳性；ER- PR- HER2- → 三阴性；诊断结论写 Luminal → HR 阳性(Luminal)
  - Luminal A：HER2-、ER+、PR 高表达、Ki-67<14%；Luminal B（HER2-）：ER+、PR 低表达或-、Ki-67 高表达；Luminal B（HER2+）：HER2+、ER+
- **BRCA1/2 突变**：有突变 / 无突变 / 未检测（区分「胚系突变」与「IHC 散在染色」，后者≠胚系突变）。
- **绝经状态**：绝经前 / 绝经后 / 未记录（判据：年龄≥60、双侧卵巢切除、自然停经≥12 月等）。
- **PD-L1 CPS**：CPS 评分（如 CPS≥10）/ 未检测（区分「CPS 评分」与「IHC PD-L1(+/-)」，后者≠CPS）。
- **转移部位**：只在「X 继发恶性肿瘤 / X 转移 / 转移瘤 / 转移灶」语境下命中（肝/骨/脑/肺/肾上腺/胸膜），避免把体检正常描述误当转移。脑转移再分**脑实质 vs 脑膜**（「脑膜转移/软脑膜/鞘内」→ 脑膜）。
- **治疗（当前 vs 既往）**：当前 = 至今/维持/继续/目前/现给予；既往 = 术后/序贯/曾予/外院/带年份的过去事件。知情同意书里的备选方案、随访模板不算。
- **治疗线**：一线 / 二线 / 三线及以上，按抗HER2/全身治疗时间轴定（如「THP 10 周期 → HP 维持 → 多线」）；时间轴不完整给「待核验」。M1 病例在 N 节点必须定线次。
- **是否手术**：切除术/根治术/保乳术/前哨淋巴结活检/腋窝清扫/全乳切除。
- **是否新辅助**：术前已给药（时间线在手术前 + 化疗/靶向），或原文出现「新辅助」。
- **pCR / non-pCR**：pCR / 病理学完全缓解 / MP 5 级 / RCB 0 → pCR；non-pCR / 未达 pCR / 残余病灶 / RCB I–III（含 RCB-II 这类带连字符写法）→ non-pCR。

## 第四步：产出综合诊断报告

报告标题「# 乳腺癌综合诊断报告」，逐节写：

1. **患者信息**（一行）：姓名 / 性别 / 年龄 / 身高体重（有则写）。
2. **主要诊断**：主诊断 + 转移/合并症诊断，按主次列出。
3. **病理与分子分型依据**：表格逐病灶列出 ER/PR/HER2/Ki-67/FISH + 判读出的分子分型；双侧乳腺或原发 vs 转移灶受体不一致时**分开列**，附一句「对照 CSCO 分子分型」判读理由。
4. **TNM 分期**：初始 → 当前（或「未记录」）；可疑未确诊的 M 分期明确标「待核实」。
5. **诊疗经过**：时间轴表格（时间 → 治疗 → 疗效）。
6. **治疗评价（对照指南）**：表格逐环节（实际方案 vs 指南推荐 + 推荐等级/证据类别 + 评价 ✓/△/⚠）；只评价有证据的环节，不替未记录的环节脑补。
7. **后续建议**：编号列出，每条尽量标注指南依据（如「AI+CDK4/6i [1A]」）。
8. **卡点 / 待核实**：缺病理/受体/分期/治疗时间轴等未记录项；安全性前置项。
9. **说明**（一行免责）：依据病历 + 指南，最终以主诊医师/MDT 决策为准。

推荐等级写 Ⅰ/Ⅱ/Ⅲ 级，证据类别写 1A/1B/2A/2B/3（见 CONTEXT.md 术语）。

## 第五步：走决策链 A→U（文字追踪）

诊断报告之后，把同一份特征映射到 CSCO 决策链（节点 A→U），**只走该病例实际命中的节点**，每个节点给三样东西：节点标签、走的分支（分支节点才有）、病历证据（一句原文/指标）。这是**回溯**：说清「这例走到了哪个节点、凭什么」，不是开方。

### 决策链结构（A→U）

| 节点 | 含义 | 类型 |
|---|---|---|
| A | 初诊乳腺癌 | |
| B | 影像 + 病理 + 分子标志物（ER/PR/HER2/Ki67/FISH、BRCA1/2、PD-L1 CPS、绝经） | |
| C | TNM 分期 + 分子分型与风险分层（HER2阳性/低表达/超低表达/三阴/HR阳性） | |
| D | M 分期：有无远处转移？ | 菱形分支 |
| E | 是否适合新辅助治疗？ | 菱形分支 |
| F | 按分子亚型选择新辅助方案（HER2+双靶 / 三阴 TP-AC+PD-1（BRCA含铂）/ HR+内分泌） | |
| G | 直接手术与腋窝评估 | |
| H | 手术 + 病理反应评估 | |
| I | pCR 还是残余病灶？ | 菱形分支 |
| J | 按风险完成术后辅助治疗 | |
| K | 强化辅助（HER2+/三阴）T-DM1 / T-DXd / 卡培他滨 / 奥拉帕利（BRCA）/ PD-1至满1年 | |
| L | 放疗 / 内分泌（绝经前 OFS+AI / 绝经后 AI+CDK4/6i）/ 抗HER2 / 免疫 | |
| M | 转移灶再活检与再分型 | |
| N | 评估既往治疗、耐药、疾病速度、治疗线、安全性 | |
| O | 按分子亚型序贯全身治疗（HER2阳性 / 低表达/超低表达 T-DXd / 三阴 PD-1/PARP / HR+ CDK4/6i） | |
| P | 特殊转移部位？ | 菱形分支 |
| Q | 骨改良药 + 局部放疗/手术评估 | |
| R | 脑转移：脑实质 or 脑膜？ | 菱形分支 |
| R1 | 脑实质转移：SRS / FSRT / 手术 / 全脑放疗 | |
| R2 | 脑膜转移：全中枢放疗 / 鞘内注射 | |
| S | 继续系统治疗与疗效评估 | |
| T | 疗效评估、毒性管理、营养/心理支持、生活质量与 MDT | |
| U | 长期随访、复发监测与临床研究/真实世界证据更新 | |

### 分支规则

- **D**：有远处转移 → 是（M1 复发/转移期）→ M；M 分期可疑但未确诊 → 待核实（停，见红线）；否则 → 否（M0 早期/局部进展期）→ E
- **E**：适合新辅助（肿块大 / LN+ / HER2+ / 三阴 / 保乳意愿，或术前已给药）→ 是 → F；否则 → 否 → G
- **F → H → I**；**I**：pCR → J；non-pCR → K；病理反应未记录 → 停在 I（需 MP/RCB/ypTNM）
- **G → J → L**
- M1 支：**M → N → O → P**；**P**：骨转移 → Q；脑转移 → R；其他内脏/软组织（肝/肺等）或无特殊部位 → S
- **R**：脑实质转移 → R1（SRS/FSRT/手术/全脑放疗）；脑膜转移 → R2（全中枢放疗/鞘内注射）
- 汇合：L / Q / R1 / R2 / S → **T → U**

```text
病例 <ID>：<性别> <年龄>岁
诊断：<诊断列表>

人群判断：<符合/不符合/部分符合 <人群> + 一句依据>
```

## 第六步：生成高亮 mermaid 图

走链完成后，把高亮 `.mmd` 写到 `diagrams/decision-chain-<case>.mmd`，并渲染 `.png` / `.svg`：

```bash
mmdc -i diagrams/decision-chain-<case>.mmd -o diagrams/decision-chain-<case>.svg -b white
mmdc -i diagrams/decision-chain-<case>.mmd -o diagrams/decision-chain-<case>.png -b white -s 2
```

命名：REAL-XXX → `decision-chain-REAL-<NNN>.mmd`；自由文本/其他 → 用病例编号或自定短 slug 替换 `<case>`。

顶部加一个**标题节点**承载病例摘要（不要用 `%%` 注释——注释不渲染进图，图里看不到）：

```
TITLE["<病例>：<分型/关键分支>"]
```

- 隐形边 `TITLE ~~~ A` 把标题置顶，**声明在所有边之后**（这样 A→U 的边仍占 `linkStyle` 0-27，高亮不错位）。
- 标题样式：`classDef caption fill:#fff,stroke:none,color:#111827,font-weight:bold;` + `class TITLE caption;`。

**原始证据要落在图上**（不只写进文字追踪）：

- **标题**写分型/IHC 原始值 + 分期 + 转移部位，如 `REAL-006：HER2阳性型（原发 FISH+；脑转移灶 HER-2 3+）<br/>pT2N1M1 Ⅳ期 脑/肺/肝/骨转移`。
- **分支边标签**写「决策 + 证据」，如 `是：M1（肝、骨继发恶性肿瘤）`、`non-pCR（RCB-II 残余病灶）`、`脑实质（无脑膜）`——只在该病例实际走过的那条边上加证据，未走的边保持通用标签（反正已灰显）。

节点全画、用**完整标签**（多行节点带 `<br/>`）。菱形用 `{…}`、其余 `[…]`；菱形 = D/E/I/P/R：

```
A[初诊乳腺癌]
B[影像 + 病理 + 分子标志物<br/>（ER/PR/HER2/Ki67/FISH、BRCA1/2、PD-L1 CPS、绝经）]
C[TNM分期 + 分子分型与风险分层<br/>HER2阳性 / 低表达 / 超低表达 / 三阴性 / HR阳性]
D{M分期：有无远处转移?}
E{是否适合新辅助治疗?}
F[按分子亚型选择新辅助方案<br/>HER2+双靶 / 三阴 TP-AC+PD-1（BRCA含铂）/ HR+内分泌]
G[直接手术与腋窝评估]
H[手术 + 病理反应评估]
I{pCR还是残余病灶?}
```

## 不确定性与红线（务必遵守）

- **未提供 ≠ 阴性**：病历没写受体/分期/病理反应/BRCA/绝经/CPS，就写「未记录/待补充」，不默认判为阴性或正常。
- **双侧/多病灶受体分开**：双侧乳腺或原发灶 vs 转移灶受体不一致时分别说明，以驱动治疗的主导病灶为准（如「右侧 HER2+、左侧 FISH 未扩增」）。
- **M 分期可疑未确诊**：疑似转移但无活检/PET 确认 → 在 D 标「M 分期待核实」，停，不要把根治性治疗与姑息性治疗混为一谈。
- **脑膜 vs 脑实质**：脑转移区分脑实质/脑膜；脑膜转移走全中枢放疗/鞘内注射、需转 CNS MDT；活动性脑实质转移先局部处理，而非直接全身序贯。
- **安全性前置**：严重骨髓抑制、器官功能不全、活动性脑转移、可疑内脏危象时，先处理安全性（升血象/抗感染/局部处理），稳定后再评估后续方案，不直接推进治疗（REAL-007 原则）。
- **下颌/颌骨病变鉴别**：骨改良药使用者出现下颌病变，需鉴别骨转移 vs 药物相关颌骨坏死 vs 感染，不能直接当转移（REAL-005 原则）。
- **合并症/干扰信息**：精神心理、跨科室诊断等作为合并症或干扰信息保留，不替代肿瘤科主病与病理证据（REAL-001/005 原则）。
- **边疑边治如实呈现**：病历「疑似转移但按局部进展期继续根治性治疗」时，如实呈现并存，不替它把 M 定为 0 或 1。
- **不越权开方**：产出「诊断 + 治疗评价 + 建议」，是**临床辅助**，不机械套标准方案，最终以主诊医师/MDT 决策为准。
